# Harish Tuition Centre

Comprehensive web platform for **Harish Tuition Centre** catering to Classes 7th, 8th, 9th, and 10th (CBSE, State Board, ICSE).

## Features
- **Teacher / Admin Portal**: Daily attendance marking with 1-click batch controls, monthly attendance % audit, subject notes publisher, video lecture manager, student directory, and test marks ledger.
- **Student Learning Hub**: Subject-wise notes reader, chapter video lecture player, personal attendance record, and test scorecard.
- **Parent Transparency Portal**: Real-time arrival status, monthly attendance %, unit test scorecard with teacher remarks, daily homework log, and direct WhatsApp / call connection to Harish Sir.
- **Public Website**: Course information, batch timings, announcements, and admission details.

## How to Run
Simply open `index.html` in any web browser, or run `start.ps1` in PowerShell to launch the local server.
